Tambur S3009'un motor kontrolü, çalışma durumları, güvenlik interlock'ları ve HMI haberleşmesi için önerilen ESP32-S3 firmware katmanı.

ESP32-S3STATE MACHINEFAIL-SAFE
01

Kontrol modeli

Firmware'i doğrudan butonlardan motor sürmeye bağlamak yerine deterministik bir durum makinesi etrafında kurmak daha güvenlidir. HMI yalnızca komut üretir; motorun gerçekten çalışıp çalışamayacağı kontrol katmanında kararlaştırılır.

02

Durumlar

IDLEMotor kapalı. Başlatma koşulları beklenir.
READYInterlock'lar sağlandı; RUN komutu kabul edilebilir.
RUNNINGHedef hız rampası uygulanır ve çalışma süresi izlenir.
PAUSEDMotor güvenli şekilde durdurulur; reçete korunur.
FAULTMotor çıkışı kesilir ve hata nedeni HMI'a aktarılır.
03

Firmware iskeleti

controller.cppc++
switch (state) {
  case IDLE:
    motor.stop();
    if (start_request && safety_ok()) state = READY;
    break;

  case READY:
    if (safety_ok()) state = RUNNING;
    else state = FAULT;
    break;

  case RUNNING:
    motor.setTargetRpm(recipe.rpm);
    if (!safety_ok()) state = FAULT;
    if (stop_request) state = IDLE;
    break;

  case FAULT:
    motor.stop();
    reportFault(fault_code);
    break;
}
